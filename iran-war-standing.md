# Iran War — Standing Sections
*Slow-moving sections of the daily briefing live here, in full. The daily briefing carries ONE bullet + link per section, and reprints a section in full only on the day it materially changes. Each header carries a "last materially changed" date so readers can see staleness at a glance.*

**Update protocol (daily agent):** For each section below, ask one question each run: *did anything material change in the last 24 hours?* If no — touch nothing here, and the briefing bullet reads "unchanged since [date]". If yes — update the section here, bump its date, and summarize the delta in the briefing's "What changed" list. Never copy a full section back into the briefing.
